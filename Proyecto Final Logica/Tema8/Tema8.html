¿Quién fue George Pólya?

George Pólya propuso un método para resolver problemas de manera lógica y organizada. Su método ayuda a desarrollar el pensamiento crítico y es muy utilizado en matemáticas, física, ingeniería y en la vida diaria.

Comprender → Planear → Resolver → Revisar

Paso 1: Comprender el problema

Consiste en leer cuidadosamente el ejercicio y entender exactamente qué se pide.

  • Identificar los datos del problema.
  • Reconocer qué información falta encontrar.
  • Entender la pregunta correctamente.

Paso 2: Elaborar un plan

Después de entender el problema, se debe pensar en una estrategia para resolverlo.

  • Hacer dibujos o esquemas.
  • Buscar patrones.
  • Utilizar fórmulas.
  • Dividir el problema en partes.

Paso 3: Ejecutar el plan

Aquí se lleva a cabo la estrategia elegida resolviendo paso a paso.

  • Realizar correctamente las operaciones.
  • Resolver con orden y cuidado.
  • Revisar cada procedimiento.

Paso 4: Revisar la solución

El último paso consiste en comprobar si la respuesta es correcta y tiene sentido.

  • Revisar operaciones y resultados.
  • Verificar si la respuesta responde la pregunta.
  • Buscar otra forma de resolver el problema.
