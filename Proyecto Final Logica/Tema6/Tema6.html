¿Qué es un conjunto?

Un conjunto es una colección de elementos que comparten una característica.

A = {1,2,3,4}

Los conjuntos se representan con letras mayúsculas y sus elementos van entre llaves.

Tipos de conjuntos

Operaciones con conjuntos

Las operaciones permiten combinar y comparar conjuntos.

A = {1,2,3}

B = {3,4,5}
A
B

Tipos de operaciones

🔹 Unión ( ∪ )
Une todos los elementos.
🔹 Intersección ( ∩ )
Elementos en común.
🔹 Diferencia ( - )
Elementos exclusivos.
🔹 Diferencia Simétrica ( △ )
Elementos diferentes.

⭕ Conjunto Vacío

Un conjunto vacío es aquel que no tiene elementos.

A = { }

También se representa con el símbolo ∅.

🔵 Conjunto Unitario

Tiene solamente un elemento.

B = {5}

Solo contiene un único elemento.

🔢 Conjunto Finito

Es un conjunto con una cantidad limitada de elementos.

C = {1,2,3,4}

♾️ Conjunto Infinito

Tiene infinitos elementos.

N = {1,2,3,4,5...}

Los números naturales son infinitos.
